# Synthetic-Healthcare-Analytics
End-to-end Healthcare Analytics: 55.5K records explored in Python + Power BI | Demographics, admissions, billing &amp; operational performance

Healthcare Analytics & Operational Performance (55,500 Records)

An end-to-end healthcare analytics project exploring patient demographics, admissions, medical conditions, billing, and hospital performance using a dataset with 55,500 initial records and 15 variables.

Cleaned and validated raw data with Python (Pandas, NumPy) to improve consistency and prepare it for exploratory analysis [EDA] and reporting.

Analyzed demographics, admission types, length of stay, billing by insurance and condition, plus hospital and doctor caseloads. Engineered analytical variables to compare trends across patient groups, time periods, and service categories.

Built interactive Power BI visualizations with DAX to communicate demographic patterns, admission trends, billing performance, and operational KPIs. Explored historical patterns for resource planning [forecasting use-case].

Maintained analytical integrity by documenting limitations and avoiding unsupported clinical claims — e.g., not interpreting normal test results as confirmed recovery.

Tools: Python | Pandas | NumPy | Matplotlib | Jupyter Notebook | Power BI | DAX
